# Operating Principles

## 1. Persistent State Over Stateless Interaction

Important operational knowledge must persist across sessions, workflows, projects, and execution cycles.

The system should continuously accumulate operational intelligence instead of resetting context repeatedly.

---

## 2. Retrieval Over Context Dumping

Large unstructured prompts reduce execution quality.

The system should retrieve:
- relevant memory
- relevant workflows
- relevant architecture
- relevant operational state

dynamically and precisely.

---

## 3. Reusable Systems Over Repeated Thinking

Repeated decisions indicate missing infrastructure.

Recurring workflows should eventually become:
- standardized
- documented
- reusable
- automatable

---

## 4. Low Cognitive Reload Cost

The system must minimize:
- re-explaining context
- reconstructing project state
- rediscovering decisions
- repeated onboarding

Operational continuity is a primary design goal.

---

## 5. AI Collaboration Optimization

All files, workflows, and system structures should optimize for:
- AI readability
- retrieval quality
- execution continuity
- operational clarity

This repository is intentionally designed for AI-assisted execution.
