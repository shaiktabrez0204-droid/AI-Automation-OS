- maintainability
- context loading precision

## [2026-05-18]

### Decision
Separate persistent context from session context.

### Reason

Mixing long-term memory with temporary operational state creates:
- noisy retrieval
- context pollution
- degraded execution quality

Separating operational layers improves:
- clarity
- retrieval precision
- memory cleanliness

---

### Long-Term Implication

This enables:
- scalable operational memory
- cleaner context injection
- more reliable AI collaboration
