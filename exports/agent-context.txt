# System Patterns

## 1. Layer Separation

Separate:
- memory
- context
- workflows
- logging
- architecture
- automation

This improves:
- retrieval quality
- maintainability
- AI reasoning clarity

---

## 2. Persistent vs Temporary State

Persistent state:
- architecture
- workflows
- important decisions

Temporary state:
- current session work
- debugging state
- active implementation focus

---

## 3. Retrieval-Oriented Organization

Organize information for retrieval, not storage.

The goal:
- fast context loading
- minimal noise
- high signal
- execution relevance

---

## 4. AI-Readable Structure

Operational context should be:
- explicit
- modular
- structured
- high signal

AI systems perform significantly better under these conditions.

---

## 5. Workflow Reusability

Repeated execution should become reusable infrastructure.

Repeated reasoning indicates missing systems.
